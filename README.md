# Local Inventory Management System (منظومة إدارة المخزون المحلي)

A lightweight web-based inventory management system built with Python, Flask, and SQLite. Designed for local store management with an intuitive user interface.

## Features (المميزات)
* Product Management: Add, track, and delete inventory items easily.
* Dashboard Analytics: Real-time summary cards showing total product types, total stock quantities, and low stock alerts.
* Local Database: Uses SQLite (store_system.db) for fast and reliable offline data storage.
* User-Friendly UI: Clean interface optimized for daily operations.

## Technologies Used (التقنيات المستخدمة)
* Python & Flask (Backend framework)
* SQLite (Database)
* HTML/CSS & JavaScript (Frontend)

---
*Developed for local business inventory tracking and portfolio demonstration.*
